# /kb — Capture what we just solved

Turn the problem we just worked through into a permanent knowledge-base entry.

1. **Pick the file.** Decide which `skills/<domain>/SKILL.md` this belongs to.
   If none fits, propose a new skill folder and ask before creating it.

2. **Write it under "Verified procedures"** in this format:

```
### <Short problem title>
**Symptom:** what the user reported / saw
**Cause:** the confirmed root cause
**Fix:** exact steps, command, or click-path
**Verified:** <today's date>
```

3. **Only record what was actually confirmed.** If we found a fix but never
   proved the cause, write the cause as `unconfirmed — suspected <X>`. Do not
   promote a guess to a fact just because the symptom went away.

4. **Strip personal data.** No names, birth numbers, addresses, machine names
   tied to a person, or case references. Describe roles and record types:
   "a user in the teacher role", "a device on the standard image".

5. **Show me the entry before saving** and confirm which file it's going into.
