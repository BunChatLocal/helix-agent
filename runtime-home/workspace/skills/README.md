# Skills

Store reusable skills in subfolders here.

Each skill should live at:

- `skills/<skill-id>/SKILL.md`

Examples:

- `skills/incident-triage/SKILL.md`
- `skills/weekly-review/SKILL.md`

The Helix Skills UI and `/skill` commands use this directory.
You can create skills manually, through the web UI, or by asking your agent to
create or update them for you.
